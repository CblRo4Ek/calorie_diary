## 📖 О проекте

Пользователь отправляет фотографию своего блюда в Telegram-бот. Модель компьютерного зрения находит (детекция) и распознает (классификация) продукты на фото, а затем сервис рассчитывает калорийность по внутренней базе калорий. Названия блюд и весь интерфейс на русском языке.

Все приемы пищи сохраняются в личный дневник питания пользователя

## 🗺️ План работ

- [ ] **Сбор данных.** Сбор и парсинг датасета с изображениями еды
- [ ] **Бейзлайн.** Обучение и тестирование простых сверточных нейросетей (CNN): классические ML-модели плохо подходят для задачи распознавания изображений
- [ ] **Продвинутые модели.** Тестирование более мощных архитектур распознавания
- [ ] **Пайплайн.** Формирование пайплайна распознавания на основе итоговой модели
- [ ] **LLM.** Интеграция языковой модели для оценки калорийности и генерации ответов
- [ ] **Telegram-бот.** Разработка бота и объединение всех компонентов
