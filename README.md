## 📖 О проекте

Пользователь отправляет фотографию своего блюда в Telegram-бот. Модель компьютерного зрения находит (детекция) и распознает (классификация) продукты на фото, а затем сервис рассчитывает калорийность по внутренней базе калорий. Названия блюд и весь интерфейс на русском языке.

Все приемы пищи сохраняются в личный дневник питания пользователя

## 🗺️ План работ

Подготовка данных для бейзлайна: **FPB + Food-101**, единый YOLO-формат без массы. Для Food-101 используется рамка всего изображения. MyFoodRepo рассматривается для продвинутой версии.

- [Исследование датасетов и итоговое решение](docs/datasets.md)
- [Краткий план действий](docs/data_plan.md)
- [Ноутбук проверки синонимов классов](notebooks/01_review_class_synonyms.ipynb)
- [Ноутбук загрузки, объединения и визуальной проверки](notebooks/02_prepare_fpb_food101.ipynb)

Окружение описано в `pyproject.toml`, точные версии зависимостей — в `uv.lock`. Используется Python 3.12 из `.python-version`. После [установки uv](https://docs.astral.sh/uv/getting-started/installation/) выполните из корня проекта:

```powershell
uv sync --locked
uv run --locked jupyter lab
```

В VS Code выберите kernel из `.venv`. Сначала запустите ноутбук проверки синонимов, затем подготовку данных. По умолчанию выполняется небольшой просмотр на реальных примерах; для полной подготовки во втором ноутбуке задайте `MODE="full"`. Все данные сохраняются в `data/` и исключены из Git.

Единственная текущая сборка находится в `data/processed/fpb_food101/`: новый успешный запуск заменяет её целиком. Каталоги, индексы источников и список примеров кешируются в `data/metadata/` и переиспользуются после перезапуска ядра. Рисунки показываются в выводе ноутбуков, без файлов в `data/reports/`.

Проверка подготовки данных:

```powershell
uv run --locked python -m unittest discover -s tests -v
```

`requests==2.34.2` — последняя стабильная версия в PyPI на 7 ноября 2026 года. При появлении нового релиза обновите ограничение и lock-файл командой `uv add requests --upgrade-package requests --exact`, затем выполните `uv sync --locked`.

`requirements-data.txt` — совместимый с pip экспорт из того же lock-файла. После изменения зависимостей обновляйте его командой `uv export --locked --format requirements-txt --no-hashes --output-file requirements-data.txt`.
