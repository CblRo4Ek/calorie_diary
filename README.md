## 📖 О проекте

Пользователь отправляет фотографию своего блюда в Telegram-бот. Модель компьютерного зрения находит (детекция) и распознает (классификация) продукты на фото, а затем сервис рассчитывает калорийность по внутренней базе калорий. Названия блюд и весь интерфейс на русском языке.

Все приемы пищи сохраняются в личный дневник питания пользователя

### Как собрать датасет для моделирования

1. С установленным `uv` выполните из корня проекта:

   ```powershell
   uv sync --locked
   uv run jupyter lab
   ```

2. Положите архивы MyFoodRepo v2.1 **train и valid** в `data/`; укажите их пути в ноутбуке 02. Для ноутбуков используйте окружение `.venv` проекта.
3. Выполните [01_review_class_synonyms.ipynb](notebooks/01_review_class_synonyms.ipynb), чтобы сохранить решения об объединении классов.
4. Выполните [02_prepare_dataset.ipynb](notebooks/02_prepare_dataset.ipynb) с `MODE = "full"` и `MYFOODREPO_SOURCE = "archives"`. Для пересборки существующего результата задайте `OVERWRITE = True`.
5. Выполните [03_eda.ipynb](notebooks/03_eda.ipynb) с `MODE = "full"`, примените очистку через `REMOVE_SIMILAR_IMAGES = True` и переразбиение через `RESPLIT_DATASET = True`, `SPLIT_FRACTIONS = (0.80, 0.15, 0.05)`.

**Для моделирования:** `data/processed/fpb_myfoodrepo_full/data.yaml` — YOLO detection, 417 классов, train/valid/test = 80/15/5 по размеченным фотографиям. Test без меток хранится отдельно и в эти доли не входит. Подробнее — [результаты EDA](docs/03_eda.md).


### Бейзлайн детекции

[04_yolo11n_baseline.ipynb](notebooks/04_yolo11n_baseline.ipynb) дообучает лёгкую YOLO11n на размеченных данных проекта, проверяет качество на val и test и сохраняет `best.pt`, `last.pt`, метрики и параметры в `models/food_yolo11n_<дата>/`. Перед запуском выполните `uv sync --locked` и подготовьте датасет по инструкции выше. Веса исходной модели COCO находятся в `models/yolo11n_coco.pt`; они не являются обученными на продуктах проекта. Подробнее — [models/README.md](models/README.md).

По умолчанию выполняется 1 эпоха для быстрого первого результата; для более продолжительного обучения измените параметр `EPOCHS` в ноутбуке или задайте переменную окружения `CALORIE_EPOCHS`. Ноутбук проверяет, что изображения и YOLO-метки существуют и что разбиения не пересекаются. Чтобы оценить обученные веса повторно без обучения, задайте путь к `best.pt` в параметре `EXISTING_WEIGHTS` ноутбука или через переменную окружения `CALORIE_EXISTING_WEIGHTS`. Классы весов должны совпадать с классами датасета.

Готовый запуск: [ноутбук с результатами и выводами](notebooks/04_yolo11n_baseline_results.ipynb), [обученные веса и метрики](models/food_yolo11n_20261110_182310_642183/). YOLO11n обучена 1 эпоху на 52 352 изображениях и 417 классах. На test (3 272 изображения): mAP50 = 0,00843 (0,84%), mAP50–95 = 0,00666 (0,67%). Качество низкое: это первый воспроизводимый бейзлайн, для практического распознавания требуется дальнейшее обучение.
