# Веса моделей

`yolo11n_coco.pt` — исходные предобученные веса Ultralytics YOLO11n для детекции 80 классов COCO. Это **не** обученная модель для 417 классов продуктов. Источник: [Ultralytics assets v8.3.0](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.pt); SHA-256: `0ebbc80d4a7680d14987a577cd21342b65ecfd94632bd9a8da63ae6417644ee1`.

После запуска `notebooks/04_yolo11n_baseline.ipynb` веса, обученные на данных проекта, сохраняются в `models/food_yolo11n_<время>/best.pt` и `last.pt`, рядом с метриками, хешами и параметрами обучения. `best.pt` выбирается по validation. Пути создаются заново при каждом запуске. Данные и логи находятся в `data/` и не отслеживаются Git.

best.pt и last.pt — обученные веса (около 5,5 МиБ каждый); оба файла сохранены по итогам единственной эпохи. metrics.csv содержит сводные метрики, test_per_class.csv — AP и число объектов по классам, run.json — настройки и хеши для проверки воспроизводимости. В test отсутствуют 4 класса; их качество этим запуском не оценивается.

Качество после одной эпохи низкое. Этот запуск задаёт исходную точку для дальнейшего обучения и сравнения моделей; он пока не обеспечивает приемлемое распознавание продуктов. Детектор также не определяет массу порции и калорийность.
