# Анализ пересечений и объединение классов

Для объединения выбраны **FPB — 138 классов** и **MyFoodRepo v2.1 — 323 класса**. Полные словари сопоставлены по названиям, затем пары рассмотрены по вырезкам размеченных объектов в [ноутбуке 01](../notebooks/01_review_class_synonyms.ipynb).

| Тип пересечения | Число пар | Примеры FPB → MyFoodRepo |
| --- | --- | --- |
| Одинаковые названия | 23 | `bread → bread`, `water → water`, `cheesecake → cheesecake` |
| Вероятные синонимы и варианты написания | 10 | `almond → almonds`, `apple_juice → juice_apple`, `capuccino → cappuccino` |
| Близкие категории разной детализации | 12 | `pizza → pizza_margherita_baked`, `black_tea → tea`, `bliny → pancake` |

После просмотра принято решение **объединить 44 из 45 рассматриваемых пар**. Единственное исключение — **`pancake` и `bliny`**, которые сохраняются раздельно как разные блюда. Объединение близких категорий в отдельных случаях укрупняет классы: например, виды пиццы MyFoodRepo относятся к общему классу `pizza` FPB.

Правила формирования единого словаря:

1. Названия и ID **0–137** классов FPB сохраняются и используются как канонические.
2. Для подтверждённых соответствий исходный COCO `category_id` MyFoodRepo переводится в ID соответствующего класса FPB. Числовые ID двух источников напрямую не приравниваются.
3. Уникальные классы MyFoodRepo и отдельный `pancake` добавляются в конец общего словаря с новыми последовательными ID.
4. Единое соответствие применяется ко всем объектам в train/val при экспорте в [ноутбуке 02](../notebooks/02_prepare_dataset.ipynb). Положение рамок при переименовании класса не изменяется.

Решения записаны в `data/review/fpb_myfoodrepo_class_decisions.csv`; объединение требует `decision=merge` и `reviewed=True`. Файл `class_mapping.csv` в готовой сборке связывает исходные названия и ID с итоговыми.

**Итоговый словарь содержит 417 классов: `138 + 323 − 44 = 417`.** Food-101 в объединении классов и обучающих данных не участвует.
